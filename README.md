# 🔐 Desafio da Senha

Um jogo de lógica e validação de senhas: cumpra 16 regras antes que o cronômetro termine!

## 🌐 Acesse o jogo

**Jogue online:** https://jphs682.github.io/desafio/

## Funcionalidades

- 16 regras validadas em tempo real
- Cronômetro de 60 segundos, iniciado ao focar o campo da senha
- Bônus de tempo ao cumprir cada regra pela primeira vez
- Regras embaralhadas a cada 12 segundos
- Contagem de caracteres visuais, incluindo emojis e bandeiras
- Colagem de texto e emojis permitida
- Barra de progresso e destaque da próxima regra pendente
- Mostrar e ocultar senha usando o campo de senha nativo do navegador
- Confetes ao vencer
- Reiniciar a partida a qualquer momento, inclusive após vitória ou derrota
- Layout responsivo e suporte à preferência por movimento reduzido

## Tecnologias

HTML5, CSS3 e JavaScript puro. Nenhuma dependência de build ou serviço de backend.

## Executar localmente

Abra `index.html` no navegador ou use Live Server no Visual Studio Code.

## Publicar com GitHub Pages

1. Mantenha `index.html`, `style.css`, `script.js` e `README.md` na raiz do repositório.
2. Abra **Settings → Pages**.
3. Escolha **Deploy from a branch**, branch `main`, pasta `/(root)`.
4. Clique em **Save` e aguarde a publicação.

## Privacidade

Este é um jogo demonstrativo. Não use senhas reais nem dados pessoais. O campo de e-mail é validado apenas no navegador e não é enviado a nenhum servidor.
